## 🚀 Featured Projects

### ✈️ SmartHangar 2.0
**Aircraft Maintenance Management & AI-Assisted Documentation**

`Java` `Spring Boot` `React` `SQL` `REST APIs` `AI Integration`

SmartHangar is my aircraft maintenance management project, inspired by my experience maintaining military aircraft.

Traditional maintenance documentation often involves disconnected systems, repetitive data entry, and paper-based processes. SmartHangar explores how modern software can improve these workflows.

**Key Features:**
- Aircraft discrepancy tracking and maintenance history
- Inspection, servicing, and maintenance record management
- AI-assisted corrective action documentation
- Offline-first functionality and data synchronization workflows
- Aircraft status dashboards and interactive visualizations
- Experimental maintenance event ledger functionality

**My Role:** Project creator and full-stack developer.
